  • sum_click / avg_score / last_click_week 파생변수
  • Fail 포함 이탈 정의 (MOOC 맥락 반영)
  • 데이터 전처리 및 품질 개선
  • 이상치 제거 2조건 + 결측값 대체 전략
  • 순서형 인코딩 (education / imd_band / age)
  • EDA: 이탈률 시각화, 상관 히트맵, IMD 분석
  • ML 모델 학습 및 성능 비교
  • XGBoost 최종 선정 (n_est=1000, lr=0.01, depth=6)
비교 모델
  • Decision Tree / Random Forest / SVM
  • XGBoost / CatBoost / LightGBM
  • MLPClassifier (PyTorch 기반)
핵심 설계 결정
Recall 최우선 최적화
이탈 학생을 미탐지(FN)하는 것이 더 큰 손실 → Recall 중심 평가 지표 설정. Fail 결과를 이탈(1)로 분류하는 도메인 기반 타겟 정의 적용.
