집중도·피로도 스코어링 엔진 — 직접 설계 및 구현
  • 집중도: focus = gaze×0.60 + head×0.40 − shoulder×0.10
  • EMA 스무딩(α=0.05) + 20~25프레임 상태 확정으로 노이즈 제거
  • 피로도: fatigue = EAR×0.25 + 경과시간×0.35 + 시선고착×0.25 + 머리움직임×0.15
  • "집중하지만 피로한 상태"를 별도 분류 — 단순 집중도와 구분
  • MediaPipe FaceLandmarker: EAR 졸음감지 · 홍채 랜드마크 시선추정 · 4×4 변환행렬 고개 방향
  • RandomForest: 52 blendshape → 82 피처, 집중·지루함·혼란·웃음·놀람 5-class
강의자 실시간 대시보드 — 학습자 집중도 카드
